Install the camd firmware

Flash an ESP32-CAM from this page. It needs Chrome or Edge on a computer, and a USB cable.

  1. Plug the board into this computer.
  2. Press the button and pick its serial port.
  3. Wait for the installation to finish.

When it finishes the camera opens a wifi network called camd-setup-XXXX. Join it with your phone to choose your wifi and copy the access token. Then run the server.
